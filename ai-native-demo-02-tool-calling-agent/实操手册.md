## 一、学习目标

> AI 不只是回答问题，而是能够判断什么时候调用外部工具。
掌握：
-   Function Calling
-   Tool Schema
-   Agent Loop
-   工具执行流程
-   LLM 与业务代码如何协作
------------------------------------------------------------------------
# 二、为什么需要 Tool Calling？
普通 Chat：
用户：
    深圳天气怎么样？
模型只能：
    根据训练数据猜测
问题：
-   数据可能过期
-   不知道实时信息
Tool Calling：
    用户问题
    ↓
    LLM分析意图
    ↓
    发现需要天气工具
    ↓
    调用 getWeather()
    ↓
    拿到真实数据
    ↓
    再次让LLM总结
------------------------------------------------------------------------

# 五、核心执行流程
用户输入：
    深圳天气
发送给LLM：
    messages
    tools
LLM返回：
    tool_calls:
    [
     {
      name:"get_weather",
      arguments:{
        city:"深圳"
      }
     }
    ]
程序发现：
需要执行工具。
执行：
    get_weather("深圳")
返回：
    晴天 32度
再次发送给LLM：
让模型生成自然语言。
------------------------------------------------------------------------
# 六、Agent Loop
最简单 Agent：
``` text
while(true){
  请求LLM
  如果LLM要求调用工具:
      执行工具
      把结果放回上下文
  否则:
      返回答案
}
```
这就是所有复杂Agent的基础。
------------------------------------------------------------------------
# 七、面试回答
问题：
什么是Tool Calling？
回答：
Tool Calling 是让LLM具备调用外部能力的机制。
模型负责理解意图和选择工具，程序负责真正执行工具，然后把结果重新交给模型生成最终答案。
LLM负责决策，代码负责执行。
