# 07 常见问题
## 1. MCP 报 `Cannot find package tsx`
确认根目录已经：
```bash
pnpm install
```
MCP Client 使用：
```text
node --import tsx apps/mcp-server/src/index.ts
```
所以 root workspace 必须能解析 `tsx`。
---
## 2. mock-company 找不到
必须从：
```bash
pnpm dev
```
启动，不建议直接切进 `apps/api` 手动执行。
---
## 3. pgvector 报维度不一致
本项目按 bge-m3：
```text
1024
```
SQL：
```text
vector(1024)
```
如果换 embedding 模型，必须同步改表维度。
---
## 4. Prometheus 抓不到 host.docker.internal
Docker Desktop（macOS/Windows）通常可直接使用。
Linux 可以把 target 改为宿主机可访问地址，或把 API 也容器化并加入同一个 Compose network。
---
## 5. Langfuse 没 Trace
检查：
```env
LANGFUSE_PUBLIC_KEY
LANGFUSE_SECRET_KEY
LANGFUSE_BASE_URL
```
然后重新启动 API。
---
## 6. 为什么 Demo 没自动写真实代码文件？
因为这是“生产架构学习版”，重点先把：
```text
Plan → Agent → Verify
```
跑通。
下一步真正 Coding Agent 可以加入：
```text
git worktree
write_file tool
run_command tool
diff
review
commit
```
并把 Harness 放在 write/commit 前后。
