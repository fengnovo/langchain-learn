# Demo 04 实操手册
## 一、为什么需要 Context Engineering
普通Prompt：
    帮我写登录页面
AI不知道：
-   项目技术栈
-   文件规范
-   命名规则
-   架构要求
结果：
每次输出可能不同。
Context Engineering：
提前给AI：
    项目规则
    架构知识
    编码规范
    任务Skill
让AI像团队成员一样工作。
------------------------------------------------------------------------
# 二、核心思想
    用户任务
    ↓
    Context Builder
    ↓
    加载：
    项目规则
    +
    Skill
    +
    相关知识
    ↓
    LLM
    ↓
    代码输出
------------------------------------------------------------------------
# 三、CLAUDE.md思想
企业通常维护：
    CLAUDE.md
    frontend-rule.md
    api-rule.md
    architecture.md
AI启动任务自动读取。
类似：
给AI安装企业大脑。
------------------------------------------------------------------------
# 四、Skill是什么？
Skill：
=
Prompt模板
-   
执行流程
-   
约束规则
例如：
frontend-review
告诉AI：
1.  检查React规范
2.  检查性能
3.  检查TS类型
------------------------------------------------------------------------

agent

frontend-rule

------------------------------------------------------------------------
# 六、面试回答
什么是Context Engineering？
答案：
Context Engineering
是围绕LLM输入上下文进行系统化设计，通过知识注入、规则管理、检索和Skill编排，让模型在复杂任务中稳定输出符合业务要求的结果。
