# 二、整体架构
    浏览器 React
        |
        | HTTP POST
        |
        ↓
    Node.js Server
        |
        | OpenAI Compatible API
        |
        ↓
    大语言模型
    模型返回：
    token1
    token2
    token3
        |
        ↓
    SSE流
        |
        ↓
    React实时显示
------------------------------------------------------------------------

# 四、启动后端
进入：
``` bash
cd server
```
安装依赖：
``` bash
pnpm install
```
创建：
    server/.env
内容：
    LLM_API_KEY=你的模型key
    LLM_BASE_URL=你的模型地址
例如：
如果使用 OpenAI：
    LLM_BASE_URL=https://api.openai.com/v1
如果使用其他兼容接口：
替换成对应地址。
启动：
``` bash
pnpm dev
```
看到：
    AI server running
说明成功。

# 六、核心代码理解
## 1. messages结构
发送给模型：
``` json
[
 {
  "role":"user",
  "content":"你好"
 }
]
```
模型理解：
user:
用户问题
assistant:
历史回答
system:
系统规则
------------------------------------------------------------------------
# 七、为什么需要 SSE
普通接口：
    请求
    ↓
    等待10秒
    ↓
    一次返回完整答案
AI体验差。
SSE：
    请求
    ↓
    token1
    ↓
    token2
    ↓
    token3
    ↓
    结束
用户感觉：
模型正在思考。
------------------------------------------------------------------------
# 八、后端核心流程
代码：
``` ts
client.chat.completions.create({
 stream:true
})
```
stream=true代表：
不要等待完整答案。
模型产生：
    你好
立即发送。
产生：
    今天
继续发送。
------------------------------------------------------------------------
# 九、前端核心流程
浏览器：
``` ts
response.body.getReader()
```
作用：
读取服务器不断推送的数据。
类似：
    服务器:
    A
    B
    C
    浏览器:
    收到A
    显示A
    收到B
    显示AB
    收到C
    显示ABC
------------------------------------------------------------------------
# 十、调试方法

2.  Base URL

    POST /chat

    data:

# 十一、完成后的能力
完成这个 Demo，你应该能够回答面试问题：
## 问：
ChatGPT为什么可以逐字输出？
答：
因为前端和后端使用流式通信。
后端调用LLM开启stream模式，模型生成token后立即返回，服务器通过SSE持续推送，浏览器读取ReadableStream并更新UI。
