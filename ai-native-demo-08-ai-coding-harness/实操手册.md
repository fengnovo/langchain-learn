# Demo 08 实操手册
## 一、为什么需要AI Harness？
AI生成代码越来越容易。
但是问题：
-   类型错误
-   风格不统一
-   引入安全风险
-   删除重要文件
所以需要质量闸门。
------------------------------------------------------------------------
# 二、什么是Harness？
Harness可以理解：
AI工作的保护层。
流程：
    AI生成代码
    ↓
    Harness检查
    ↓
    通过
    ↓
    提交
------------------------------------------------------------------------
# 三、核心组件
## 1. Hook
Git提供生命周期。
例如：
commit之前：
执行检查。
    git commit
    ↓
    pre-commit hook
    ↓
    检查
    ↓
    允许/拒绝
------------------------------------------------------------------------
## 2. Lint Gate
检查：
-   ESLint
-   TypeScript
例如：
禁止：
any
------------------------------------------------------------------------
## 3. Security Gate
检查危险操作。
例如：
禁止：
rm -rf
修改.env
提交密钥
------------------------------------------------------------------------
## 4. Test Gate
运行：
unit test
保证：
代码可用。
------------------------------------------------------------------------
# 四、运行
进入：
    cd harness
安装：
    pnpm install
运行：
    pnpm dev
观察：
Harness检查流程。
