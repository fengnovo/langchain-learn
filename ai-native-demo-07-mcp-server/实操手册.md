# Demo 07 MCP Server 实操手册
## 一、为什么需要MCP？
以前：
每个AI产品自己定义工具。
例如：
Cursor有自己的插件。
Claude有自己的插件。
问题：
工具生态无法复用。
MCP：
定义统一协议。
类似：
USB接口。
AI：
只需要支持MCP。
就可以连接：
文件
数据库
Git
飞书
---
# 二、MCP角色
## MCP Client
负责：
连接Server。
例如：
Claude Code
---
## MCP Server
负责：
提供能力。
例如：
代码搜索服务。
---
# 三、Tool
Tool就是：
AI可以调用的函数。
例如：
```
search_code(keyword)
```
AI:
我需要查找登录代码。
调用：
search_code("login")
---
# 四、企业场景
真实公司：
可以做：
code-mcp
查询代码。
doc-mcp
查询飞书文档。
jira-mcp
查询需求。
sentry-mcp
查询错误。
---
# 五、运行
进入：
mcp-server
安装：
npm install
启动：
npm run dev
另一个终端运行client。
观察：
Agent发现工具。
调用工具。
获取结果。
