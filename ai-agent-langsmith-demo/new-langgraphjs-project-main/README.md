核心逻辑定义在 `src/agent/graph.ts` 中，展示了一个简单的聊天机器人：它可以在保留先前消息上下文的同时响应用户查询。

## 功能说明

这个简单的聊天机器人会：

1. 接收用户的**消息**作为输入
2. 保存对话历史
3. 返回占位响应并更新对话历史

本模板提供了一个易于自定义和扩展的基础，可用于创建更复杂的对话式智能体。

## 快速开始

1. 安装 [LangGraph CLI](https://langchain-ai.github.io/langgraph/concepts/langgraph_cli/)。

```bash
npx @langchain/langgraph-cli
```

2. 创建 `.env` 文件。这个入门应用本身不需要任何密钥，但如果之后连接 LLM 提供商或其他集成服务，通常需要提供相应的 API 密钥。

```bash
cp .env.example .env
```

3. 如有需要，在 `.env` 文件中添加 LangSmith API 密钥。

```
LANGSMITH_API_KEY=lsv2...
```

## 如何自定义

1. **添加 LLM 调用**：你可以从 [LangChain.js 生态系统](https://js.langchain.com/docs/integrations/chat/)中选择并安装聊天模型封装，也可以在不使用 LangChain.js 的情况下直接使用 LangGraph.js。
2. **扩展图**：聊天机器人的核心逻辑定义在 [graph.ts](./src/agent/graph.ts) 中。你可以修改此文件以添加新节点、新边，或者改变对话流程。

你还可以通过以下方式扩展本模板：

- 添加[自定义工具或函数](https://js.langchain.com/docs/how_to/tool_calling)，增强聊天机器人的能力。
- 实现额外逻辑，以处理特定类型的用户查询或任务。
- 集成[外部 API 或数据库](https://langchain-ai.github.io/langgraphjs/tutorials/rag/langgraph_agentic_rag/)，添加检索增强生成（RAG）能力，从而提供更加定制化的响应。

## 开发

在迭代图的过程中，你可以编辑历史状态，并从之前的状态重新运行应用，以调试特定节点。本地修改会通过热重载自动生效。你可以尝试：

- 修改系统提示词，为聊天机器人赋予独特的个性。
- 向图中添加新节点，以构建更复杂的对话流程。
- 实现条件逻辑，以处理不同类型的用户输入。

后续请求会追加到同一个线程中。你可以使用右上角的 `+` 按钮创建全新线程，并清除之前的历史记录。

有关更高级的功能和示例，请参阅 [LangGraph.js 文档](https://langchain-ai.github.io/langgraphjs/)。这些资源可以帮助你针对具体用例调整本模板，并构建功能更完善的对话式智能体。

LangGraph Studio 还集成了 [LangSmith](https://smith.langchain.com/)，支持更深入的链路追踪和团队协作，帮助你分析并优化聊天机器人的性能。
